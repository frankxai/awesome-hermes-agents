# Roadmap

## Now

- Keep this repo source-grounded and clearly independent from Nous Research.
- Maintain a founder-friendly local setup path.
- Publish reusable swarm specs and deploy templates.

## Next

- Add a registry compiler that turns `configs/*.json` into dashboard rows, `.env.example` files, and cloud manifests.
- Add Docker Compose examples with one Hermes profile per service.
- Add a LiteLLM Agent Platform bridge example for managed-agent API compatibility.
- Add a Cloudflare Access front-door recipe for exposed dashboards.
- Add an upstreamable Hermes Desktop patch note or issue template for the Windows safe-graphics workaround.

## Later

- Build a Starlight web control plane that reads the swarm spec and shows profile health.
- Add cost/risk scoring for each agent profile.
- Add a provenance linter that flags claims confusing Hermes Agent, Hermes models, Nous Portal, and third-party managed products.
