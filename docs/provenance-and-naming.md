# Provenance and Naming

This repo should make provenance impossible to misunderstand.

## Official Attribution

Use this language:

> Hermes Agent is an open-source agent framework by Nous Research. This repo is an independent FrankX/Starlight curation and architecture guide for operating Hermes Agent profiles and agent fleets.

When linking:

- Official Hermes Agent repo: `https://github.com/NousResearch/hermes-agent`
- Official docs: `https://hermes-agent.nousresearch.com/docs/`
- Nous Portal: `https://portal.nousresearch.com/`

## Starlight Attribution

Use this language:

> Starlight contributes an operating pattern: cross-tool memory, SIP provenance, profile topology, deployment templates, and Codex-managed configuration generation around Hermes Agent.

## Model vs Agent

Hermes model family and Hermes Agent are not the same thing.

- "Hermes 3" is model lineage.
- "Hermes Agent" is an agent framework/runtime.
- A product powered by Hermes 3 is not automatically a managed Hermes Agent offering.

## Repo Naming

Recommended names:

- `awesome-hermes-agents`
- `hermes-agent-patterns`
- `starlight-hermes-ops`

Avoid:

- `official-hermes-*`
- `nous-hermes-*`
- names that imply ownership by Nous Research.

## Public Disclosure Block

Add this to public docs:

```markdown
Disclosure: Hermes Agent is developed by Nous Research. This guide is independent and curated by FrankX/Starlight. Product names and trademarks belong to their respective owners.
```
